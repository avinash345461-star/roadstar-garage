# Roadstar's Garage Detailing Studio

Official web portal and bay booking system for **Roadstar's Garage** (रोडस्टार्स गेराज) — Varanasi's premier vehicle detailing studio located in Ganpathi Nagar, Konia, Varanasi.

## Features
- **Mobile-First Responsive Interface**: Tailored for all smartphone screens with iOS safe-area docking, bottom navigation controls, and non-clipping layouts.
- **Service Catalog & Bay Specifications**: Detailed procedures for high-pressure foam washes, 9H nano-ceramic coatings, motorcycle detailing, underbody restoration, and interior cabin extraction.
- **Direct WhatsApp & Phone Integration**: Instant contact buttons linking directly to garage helpline (`081154 63232`).
- **Interactive Appointment Scheduler**: Real-time modal booking dispatch for four-wheelers and motorcycles.
- **Google Maps Navigation**: Instant GPS link to the studio behind Mangal Murti Hero Agency, Konia, Varanasi.

## Tech Stack
- **Framework**: [React 19](https://react.dev/) + [Vite](https://vite.dev/)
- **Styling**: [Tailwind CSS v4](https://tailwindcss.com/) with pure dark mode & glassmorphism aesthetic
- **Animations**: [Framer Motion](https://www.framer.com/motion/)
- **Icons**: [Lucide React](https://lucide.dev/)

## Getting Started

### Prerequisites
- Node.js (v18+)
- npm or pnpm

### Installation
```bash
git clone https://github.com/avinash345461-star/roadstar-garage.git
cd roadstar-garage
npm install
npm run dev
```

### Production Build
```bash
npm run build
npm run preview
```
